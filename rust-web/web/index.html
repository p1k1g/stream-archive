PREFERENCES

환경 설정

이 분류에 표시할 설정이 없습니다.

SOOP_LIVE_SETTING.ini/.bak를 선택하면 일반 설정과 VOD 도구 경로를 SQLite로 가져옵니다. 비밀번호/API Key는 안전상 자동 가져오지 않습니다.

Phase 7부터 Watcher는 SQLite를 직접 읽습니다. INI/TXT는 호환/백업용 미러이며 런타임 원본이 아닙니다.

SOOP / Worker 인증

저장된 값은 API/화면으로 다시 노출하지 않습니다. Windows CurrentUser DPAPI로 암호화하며 기존 dpapi:v1 값과 호환됩니다.

데이터 백업 / 복원

백업 위치 -정책 -

기본 백업 위치는 프로그램 폴더 바깥의 soop-recorder-backups입니다. 따라서 portable 패키지를 다시 만들거나 프로그램 폴더를 교체해도 백업이 같이 삭제되지 않습니다. 필요하면 SOOP_BACKUP_DIR 환경변수로 위치를 바꿀 수 있습니다.

생성종류파일크기SHA-256무결성

복원은 Watcher와 VOD가 모두 중지되고 VOD 다운로드 큐가 비어 있는 상태에서만 가능합니다. 복원 직전에 현재 DB를 자동 안전백업하고, 과거 로그인 세션이 되살아나지 않도록 모든 세션을 무효화합니다.
