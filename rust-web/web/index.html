이 분류에 표시할 설정이 없습니다.

SOOP_LIVE_SETTING.ini/.bak를 선택하면 일반 설정과 VOD 도구 경로를 SQLite로 가져옵니다. 비밀번호/API Key는 안전상 자동 가져오지 않습니다.

Phase 7부터 Watcher는 SQLite를 직접 읽습니다. INI/TXT는 호환/백업용 미러이며 런타임 원본이 아닙니다.
